# 勿停 · 规则文档（实现依据，v2）

> 1~4 人共乘一辆车行驶在深夜无限夜路上。核心张力只有一条：**一切收益都要求慢下来，
> 而一切慢都在喂养车后面的东西**。横版无尽、距离即成绩。
> v2 三根支柱：**真弯道**（连续转向）、**信息不对称**（驾驶员看不清，副驾驶靠地图看）、
> **夜行者主动袭击停下的车**（「别停」不再是抽象的尾压条）。

## 1. 基本流程

- **1~4 人**（solo 可开局=一人全占）；大厅选「勿停」建房，房主开始即上路。
- **服务器模拟制**：车速/转向/弯道/夜行者/尾压/事件全部服务端权威模拟（15Hz tick、~10Hz 全量视图广播）；
  客户端只发按键意图 `vInt`（专用令牌桶 10/s 突发 20，超速静默丢弃不计洪泛）。
- **仅电脑**：键盘 + 鼠标。触屏设备大厅里入口置灰，已进房者看到整屏提示（可转观战/退出）。
- **持键与边沿**：油门/刹车/转向为持键（按下发、松开发；掉线、切岗位、失焦、切后台自动清零）；
  车窗/大灯/岗位/喊话/标记为点按。
- 刹车优先于油门；被夜行者扒着时加速打折（×0.7）。

## 2. 岗位（信息不对称即玩法）

| 岗位 | 能做 | 看到 |
| --- | --- | --- |
| 驾驶员 | 油门/刹车/转向、鼠标环顾 | 整幅 3D 挡风玻璃 + 仪表盘；**没有地图** |
| 副驾驶 | 左右车窗、大灯、地图标记、快捷喊话 | 大地图（后 60m ~ 前 300m）+ 小窗 3D + 仪表 |
| 单人局 | 全部 | 3D + 角落小地图 |

- 开局默认：座位最靠前的是驾驶员，其余副驾驶；任何人按 Tab（或双按钮）自己切换，可多人同驾。
- 切岗位即松手（原岗位持键全部清零）；服务端按岗位校验权限，非驾驶位的驾驶意图静默忽略。
- 无人驾驶（在线且在驾驶位的人数为 0）时全屏警示；驾驶员被拖走后其余人切岗位接管。
- 副驾驶的「说」：① **快捷喊话** 1-9（左弯！/右弯！/急弯！减速/前方有东西！/它冲过来了！快走/它追上来了！加速/左窗！/右窗！/停车加油），
  每人 1.2s 冷却，驾驶员画面上方大字闪现 3 秒；② **地图标记**：副驾驶点地图任意位置（或按 S/↓ 标记最近危险），
  驾驶员画面上出现带距离的旗标，出屏/在身后时贴边带箭头。没有自由文本喊话（不做审核面）；语音靠玩家自己。

## 3. 车辆与转向

| 项 | 值（v0 待调参） |
| --- | --- |
| 速度域 | 0–120 km/h，**勿停线 30** |
| 油门/滑行/刹车 | +25/s、−15/s、−60/s |
| 油耗 | `0.6 + 0.6×(速度/120)` %/s；油尽油门失效且速度锁 ≤15 |
| 车耐久 | 2/3/5（房主可调，默认 3）；归零全灭 |
| 路面 | 三车道，半宽 5.25m；护栏在 7.4m |

**转向（前后端同源 `stepSteering`，客户端预测共用）**
- 车有横向位置 `lateral`（米，正=路中心右侧）与车头相对角 `rel`（rad，正=车头偏右）。
- 按住方向键：`rel` 以 1.0 rad/s 朝按键方向变化（静止打不动方向）；松键：`rel` 以 0.9/s 回正；
  弯道：`rel −= κ·v·dt`（道路在车下转动 = 离心外甩，越快越狠）；`rel` 钳 ±0.5；`lateral += v·sin(rel)·dt`。
- 出路面（|lateral| > 5.25）：额外减速 15 km/h/s、画面颠簸、刮擦噪音使猎影距离每秒 −2。
  减速必须小于油门加速（25）——否则车停在路肩上就再也开不动（静止打不了方向）。
- 撞护栏（|lateral| ≥ 7.4，冷却 1.2s）：耐久 −1、速度 ×0.25、**弹回路面内侧**（距路缘 0.8m）且车头朝向路面。

## 4. 弯道

- 序列惰性生成（车头前方 900m）：直道 110–230m（开局直路 200m），弯道 80–180m，半径随路牌数递减 210→115m。
- 进出弯各 20m 线性渐变（`curvatureAt`）；同向连续弯道总转角 ≤1.6 rad（保证前方道路落在地图里）。
- 房间参数「弯道」：缓 ×0.7 / 标准 ×1 / 急 ×1.3（曲率乘数）。
- 3D 画面与地图共用同一份中心线积分（客户端 `buildRoadPath`）：地图上的弯就是眼前的弯。

## 5. 猎影（尾压）

- 距离 0–100：速度≥勿停线每秒 +4；低于每秒 −4/−6/−8（凶度 缓/标准/凶）。
- **噪音**（撞路障、碾尸群、撞护栏、撞飞夜行者）额外 −8。
- 归零即扑击：耐久 −1、距离回置 50。
- 表现：车后带红眼的高大黑影，只在后视镜（实时画面）或回头时可见；地图上是车后的红色光团（尾距 100 → 130m，归零 → 10m）。

## 6. 夜行者（会主动袭击停下的车）

状态机：`游荡 wander → 被惊动冲刺 hunt → 扒车 latched`，以及 `放弃回位 return`、`被甩飞 thrown`。

| 项 | 值 |
| --- | --- |
| 出现 | 独立生成流：第一只在第 1 号路牌之后 40–160m；之后每隔 330m 一只，每过一块路牌缩短 15m（最短 150m，±30% 抖动）；第 4 号路牌起三成概率成对（相距 12–30m） |
| 游荡 | 在路上缓慢横移（周期 12–25s，活动范围 ±4.2m） |
| **停车判定** | 车速 < 10 km/h（且已发车：车第一次到过 25 km/h 之前不惊动） |
| 惊动范围 | 沿路 90m 内的全部夜行者 |
| 冲刺 | 5.5 m/s × (1 + 0.06×路牌数)，朝车直奔 |
| 追上 | 沿路距离 ≤2.8m 且横向 ≤2.3m → 扒住该侧车门 |
| 撕扯 | 扒上后下一拍起 1.6s 开始，之后每 2.5s 耐久 −1（**多只共用一个节奏**）；加速 ×0.7。1.6s 是给「立刻满油门」留的活路：17.5km/h/s × 1.6s 刚好冲过甩脱线 |
| 爬窗 | 扒车侧车窗开着持续 2.5s → 爬进来：拖走活着的开窗者，无人认领则破窗耐久 −1；关窗即打断 |
| 甩脱 | 车速 ≥ 25 km/h：扒着的全部甩飞（计入搏斗）；没追上的放弃、走回原位（2.2 m/s） |
| 行驶中撞上 | 车速 ≥20 km/h：耐久 −1、速度 ×0.35、噪音；10–19 km/h：低速撞开（只减速 ×0.7，不伤车） |

- 同一时间窗爬者不爬已有夜行者扒着的那一侧。
- 加油必须停稳（<5 km/h）→ 每次加油都是一次赌博；副驾驶要在地图上盯着合围并喊「快走」。
- 表现：车灯照得到是灰白人形，照不到只剩一对反光的眼睛；冲刺有尖啸，拍打有闷响，画面持续震动。

## 7. 窗与窗爬者（侧压）

- 窗默认全关。爬窗调度间隔 = `14s ÷ (档位 × tier 乘数 × 灯光)`，档位 0.6/1/1.6，tier 乘数 `1+0.15×路牌数` 封顶 3，灯亮 ×1.5；钳 4–60s，开局宽限 8s。
- **两窗全关就无从下手**（短延迟重试）；同一时间只进行一只。
- 流程：预警 1.2s（抓挠声）→ 爬入计时 3s → 期间关窗即挫败；走满仍未关：拖走当前开窗者（无归因则耐久 −1），窗自动关上。
- 被拖走者不响应操作，下一个路牌复活。
- 表现：窗爬者真的扒在车窗外，鼠标转头看过去它贴在玻璃上。

## 8. 路面事件（按横向位置判定）

- 间距 120–280m；首个 150m（路障 34% / 尸群 20% / 搜掠 46%）。加油站每 500±100m 一座（棚区 30m），停稳每秒 +30 油。
- **路障**：占一条车道（半宽 1.3m）；tier 3 起 35% 是横跨两条车道的宽路障（半宽 3.4m）。撞上 = 速度 ×0.4 + 耐久 −1 + 噪音。
- **尸群带**：横跨两条车道（半宽 3.6m）×40m；碾过（≥10 km/h）= 速度 ×0.5 + 噪音（不伤车）。
- **搜掠点**：路肩（左右交替），70% 油 +15~25 / 30% 耐久 +1；收取条件 = **同侧外侧车道** + 该侧窗开 + 车速 ≤50，归因当前开窗者。
- **路牌**：间隔 200/300/400/600（默认 400）；通过 = tier+1 + 复活被拖走者。
- 目标模式：0=纯无尽；5/10/15=到达即全员逃生。

## 9. 断线与离开

- 掉线保留座位，持键立即失效；重连后客户端对照视图自动补报仍按着的键。**全员断线 30s 就地终局**（reason=idle）。
- 主动离开/被踢：标记 left（留在结算里），清持键、喊话冷却与开窗归因；无人在车上即终局（reason=leave）。

| --- | --- |
| 驾驶 | W/↑ 油门 · S/↓ 刹车 · A/← D/→ 转向 · 鼠标环顾（点击锁定，停手 1.5s 回正，Esc 释放） |

| 通用 | Q/E 车窗、F 大灯、R 标记（单人局方向键归驾驶时用）· Tab 切岗位 |

守卫：输入框/下拉框聚焦、弹层打开、终局时不响应；窗口失焦、页面隐藏自动松键。

## 11. 记账口径

- 终局三件套同心有灵犀：审计 end + 房间对局记录（在车上/被拖走/已离开）+ matchlog（逃生成功全员 rank=1，否则 rank=2）。
- 按键意图属高频流不埋 act；广播瘦身：10Hz 全量帧不重复捎带日志（首帧仅尾部 60 行）。
- 观战者在终局自动回到房间等待页；对局中入座者本局观战，下一局自动加入。

## 12. 画面与性能（客户端）

- three.js / WebGL，按需加载（进勿停对局才下载，约 150KB gzip）；WebGL 不可用时给明确提示。
- 世界窗口：车后 96m ~ 车前 400m；指数雾约 230m 外没入黑暗；车灯是两个真实聚光灯。
- 世界在车下滑动与转动（车固定在原点），锚点每 4m 才重排几何与实例；松林/反光柱/护栏立柱实例化。
- 后视镜：朝后的相机渲染到 384×128 贴图，隔帧一次，那一遍隐藏车厢。
- 首版不开实时阴影（保低端电脑 60 帧）；像素比上限 1.5。
