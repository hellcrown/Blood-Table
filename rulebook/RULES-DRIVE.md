# 勿停 · 规则文档（实现依据）

> 1~4 人共乘一辆车行驶在深夜无限直路上。核心张力只有一条：**一切收益都要求慢下来，
> 而一切慢都在喂养车后面的东西**。横版无尽、距离即成绩；服务器模拟制（客户端只发按键意图）。

## 1. 基本流程

- **1~4 人**（沿用房间人数上限，solo 可开局）；大厅选「勿停」建房，房主开始即上路。
- **服务器模拟制**：车速/油量/尾压/事件全部服务端权威模拟（15Hz tick、~10Hz 全量视图广播）；
  客户端只发按键意图 `vInt`（专用令牌桶 10/s 突发 20，超速静默丢弃不计洪泛）。
- **持键与边沿**：油门/刹车/探头为持键（按下 on / 松开 off；掉线与切后台自动清零）；
  换道/开窗关窗/大灯为点按；瞭望标记一键标记前方最近危险（随视图转发全队可见，3 秒渐隐）。
- 任何人都能执行任何操作（没有固定站位）；刹车优先于油门；换道冷却 0.4s。

## 2. 车辆

| 项 | 值（v0 待调参） |
| --- | --- |
| 速度域 | 0–120 km/h，**勿停线 30** |
| 油门/滑行/刹车 | +25/s、−15/s、−60/s |
| 油耗 | `0.6 + 0.6×(速度/120)` %/s；油尽油门失效且速度锁 ≤15 |
| 车耐久 | 2/3/5（房主可调，默认 3）；归零全灭结算 |

## 3. 猎影（尾压）

- 距离值 0–100：速度≥勿停线每秒 **+4**；低于每秒 **−4/−6/−8**（凶度 缓/标准/凶，房主可调）。
- **噪音事件**（撞路障、碾尸群）额外 −8——噪音把猎影招过来。
- 归零即**扑击**：车耐久 −1、距离回置 50、全屏红闪。
- 氛围口径：**从不渲染实体**——后视镜两枚红点的大小/亮度/闪频 ∝ 逼近度，心跳音量同源。

## 4. 窗与窗爬者（侧压）

- 窗默认全关。爬窗调度间隔 = `14s ÷ (爬窗档位 × tier 乘数 × 灯光)`，档位 0.6/1/1.6（低/标准/高），
  tier 乘数 `1+0.15×路牌数` 封顶 3，灯亮 ×1.5；钳制 4–60s，开局宽限 8s。
- **两窗全关就无从下手**（短延迟重试等开窗）；**同一时间只进行一只**。
- 流程：预警 1.2s（抓挠声+边框红光）→ 爬入计时 3s → 期间关窗即挫败（无伤害，重新调度）；
  计时走满仍未关：**拖走当前开窗者**（无归因则直接车耐久 −1），窗自动关上。
- 被拖走者不响应操作，**下一个路牌复活**；全员被拖走 = 无人驾驶自然滑停 → 尾压 → 扑击 → 车毁，
  死亡螺旋无特判。

## 5. 路面事件（种子驱动，车头 600m 内保持有生成）

- 间距 120–280m；首个事件 150m。权重：路障 34%（tier≥3 起 40% 概率占两条车道）、尸群 20%、搜掠 46%。
- **路障**：车道判定，撞击 = 速度 ×0.4 + 耐久 −1 + 噪音。
- **尸群**：占两车道 ×40m 区，碾过（≥10km/h）= 速度 ×0.5 + 噪音（无耐久损伤）。
- **搜掠点**：路肩（左右交替），70% 油 +15~25 / 30% 耐久 +1；收取条件 = **对应侧窗开 且 速度≤50**，
  归因当前开窗者。
- **加油站**：每 500±100m 一座（棚区 30m），停稳（<5km/h）每秒 +30 油。
- **路牌**：间隔 200/300/400/600（房主可调，默认 400）；通过 = tier+1 + 复活被拖走者 + 风切音。
- 目标模式：0=纯无尽冲距离；N（5/10/15）=到达即全员逃生成功（房主可调）。

## 6. 断线与离开

- 掉线保留座位，持键立即失效；**全员断线 30s 就地终局**（reason=idle）。
- 主动离开/被踢：标记 left（留在结算里），其开窗归因清空；无人在车上即终局（reason=leave）。
- 重连自动回到车上（视图补全量帧）；车是共乘的，一人重连不影响其他人驾驶。

## 7. 记账口径

- 终局三件套同心有灵犀：审计 end（含 results 全量）+ 房间对局记录（名次行写终局状态：
  在车上/被拖走/已离开）+ matchlog（合作制无个人胜负：逃生成功全员 rank=1，否则 rank=2）。
- 爬窗属高频流不埋 act（同 dStroke 三不口径）。
- 观战者在终局自动回到房间等待页；对局中入座者本局观战，下一局自动加入。
